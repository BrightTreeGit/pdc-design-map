PDC tools: one place for the download scripts
==============================================
Double-click a "<Site> - get ..." file. Results go into that site's own folder.
Keeping one copy of each script here (instead of a copy in every site folder) means a fix reaches every site at once.

  Bellbunya - get photo history.bat             all aerial photos 1950s to now -> Bellbunya\Aerial and Google Maps\history + old_photos
  Noosa Forest Retreat - get photo history.bat  same for Noosa Forest Retreat
  Annwn - get site data.bat                     new block: boundary, elevation, aerial and rainfall -> Annwn\Site data

When a run finishes, tell Claude "<site> photo history is ready" (or "<site> site data is ready").
Master copies of every script are also kept in the private GitHub archive (BrightTreeGit/pdc-design-map, scripts/).
